# WASL — مصفوفة المطابقة مع وثيقة المعايير

| المجال | التنفيذ في النسخة المحدثة الاحترافية | الحالة |
|---|---|---|
| **الهوية دون هاتف أو بريد** | الهوية محلية بالكامل ومعرّف المستخدم يُنشأ عبر مصدر عشوائي تشفيري آمن `Random.secure()` بصيغة `WASL-XXXXXXXXXXXX`. | **مطبق بالكامل** |
| **عدم استخدام جهات الاتصال** | لا تطلب أو تستخدم جهات اتصال الجهاز نهائياً؛ الإضافة فقط برمز المعرف أو QR. | **مطبق بالكامل** |
| **تقليل البيانات والخصوصية** | لا يجمع التطبيق أي محتوى أو بيانات وصفية؛ والخادم الوسيط `wasl_relay.py` عديم الحالة (Stateless) ومبني بالكامل في الذاكرة الرام (In-Memory). | **مطبق بالكامل** |
| **تشفير شامل E2EE** | تشفير AES-256-GCM ومفاتيح X25519 محلية مع HKDF-SHA256، وحذف أي أكواد تجريبية قديمة. | **مطبق بالكامل** |
| **توثيق الاقتران** | Ed25519 بتمثيل canonicalPayload موحد، requestId، challenge عشوائي تشفيري، و expiry، مع التحقق الرقمي للتوقيع. | **مطبق بالكامل** |
| **التخزين الآمن وتصفير البيانات** | مفاتيح الهوية والجلسات في `FlutterSecureStorage` مع خاصية التدمير الآمن الشامل (Zeroize Wipe). | **مطبق بالكامل** |
| **الصلاحيات** | لا يطلب الموقع أو جهات الاتصال أو SMS أو الحسابات؛ الميكروفون والملفات تطلب عند تفعيل الميزة فقط. | **مطبق بالكامل** |
| **الرسائل وتأكيدات التسليم** | دعم النصوص والصوت والملفات مع تأكيدات الحالة (تم الإرسال ✓، تم التسليم ✓✓، تم القراءة ✓✓). | **مطبق بالكامل** |
| **الحذف للطرفين والاختفاء** | حذف محلي وحذف للطرفين (Delete for Everyone) بإشارات تحكم مشفرة، ومؤقت اختفاء يبدأ من الإرسال أو القراءة. | **مطبق بالكامل** |
| **Offline-First ومنع التكرار** | معرّف UUID فريد لكل رسالة لمنع التكرار (Idempotency)، وطابور outbox مشفر يعيد الإرسال تلقائياً. | **مطبق بالكامل** |
| **أولوية الرسائل النصية** | طابور Outbox ذكي بأولويات (Priority Queue: النصوص والتحكم = 1، كتل الملفات والوسائط = 2). | **مطبق بالكامل** |
| **نقل واستئناف الوسائط** | تقطيع الملفات المشفرة إلى Chunks بحجم 64KB مع تتبع نسبة التقدم وتشغيل الصوت مباشرة في الذاكرة. | **مطبق بالكامل** |
| **إدارة الاتصال والشبكة** | إعدادات مخصصة لخادم الترحيل (IP/Port/WSS)، إعادة الاتصال التلقائي الذكي (Exponential Backoff)، ونبضات Heartbeat. | **مطبق بالكامل** |
| **دعم العربية والإنجليزية** | دعم كامل للغتين العربية والإنجليزية مع مراعاة اتجاهات النصوص RTL وLTR والوضع الليلي والنهاري. | **مطبق بالكامل** |
